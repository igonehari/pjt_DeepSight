# 03. 얼굴 자동 모자이크 — 프로젝트 명세서

- **학습자**: Python 예제 복사·실행 수준 고3 / **기간**: 5주 × 주 7시간
- **조 인원**: 6~7명 / **난이도**: 초급 / **실행 장비**: 일반 Windows PC(CPU)
- **문제 정의**: 사진 속 얼굴을 검출해 모자이크하고 새로운 이미지로 저장한다.
- **준비 데이터**: 동의받은 얼굴 사진 20장
- **모델**: `shared/models/haarcascade_frontalface_default.xml` (기존에 훈련된 모델·검출기를 사용)
- **알려진 한계**: Haar Cascade 누락 가능, 완전한 비식별 보장 불가

## 기능 요구사항
- **F1 필수**: 실제 입력을 읽고 입력이 없으면 이해할 수 있는 오류 메시지를 출력한다.
- **F2 필수**: 사전 학습 모델/검출기로 인식 또는 관절 좌표 분석을 수행한다.
- **F3 필수**: 분석 결과가 표시된 새 이미지/영상 또는 CSV 파일을 `outputs`에 저장한다. 원본은 수정하지 않는다.
- **F4 권장**: 정답표와 프로그램 결과를 비교하고 오탐·미탐 또는 개수 오차를 기록한다.
- **F5 선택**: 여러 파일 반복 처리, 그래프 또는 결과 표시 개선 중 1개 추가.

## 사용 시나리오
- 정상: 정면/측면/다수/얼굴 없음
- 예외: 입력 폴더가 비어 있음, 잘못된 파일 형식, 모델 파일 없음, 얼굴/물체/손/자세가 검출되지 않음.

## 정량 평가
- 평가 대상: **이미지별 실제 얼굴 수와 검출·처리된 얼굴 수**
- 20장 이미지 또는 대표 프레임 20개를 사람이 확인해 정답을 만든 뒤 비교.
- 정확도 90% 같은 **사전 성능 목표는 부여하지 않음**. 검출 실패를 재현하고 이유를 설명하면 평가 인정.
- 사람 수/개수 비교에는 절대오차 `|예측 수 - 실제 수|`를 사용할 수 있음. 얼굴 검출은 검출 수 일치율이 박스 정확도와 다름.

## 학생 역할 (7명 기준)
1. 조장·통합 1명: 실행 통합, 일정, 이슈.
2. 데이터 1명: 사진/영상 20개 또는 영상 2개, 권리 확인.
3. AI 코드 2명: 모델 실행, 탐지 조건 변경.
4. 표시·저장 1명: `outputs`와 파일명/CSV 확인.
5. 검증 1명: `ground_truth.csv`, `test_cases.csv`, 오류 분석.
6. 문서·발표 1명: README, PPT, 시연. 6명 조는 조장과 발표 담당 겸임.

## 5주 일정 / 게이트
| 주 | 핵심 작업 | 필수 제출물 |
|---|---|---|
| 1주 | 환경 설치, 모델 준비, 파일 1개 로드 | 사진/영상 입력 성공 화면 |
| 2주 | 핵심 코드 실행 및 결과 저장 | **Go/No-Go: 입력→처리→저장 성공** |

| 5주 | 통합 테스트, 발표 | 실행 소스, 출력물, 3분 시연, 한계 설명 |

## 2주차 실패 시 축소
- 새 모델 학습, GUI, 웹캠 기능을 제거하고 단일 사진 또는 10초 영상 하나부터 성공시킵니다.
- 모델 자체를 열 수 없으면 지도교사가 제공한 환경으로 변경합니다. 모델 없는 단순 시각화로 바꾼다면 **프로젝트 목표를 변경했다고 명시**합니다.
