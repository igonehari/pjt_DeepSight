# 데이터 준비 — 03. 얼굴 자동 모자이크

이 패키지에는 저작권에 문제가 없는 무료 사이트에서 다운로드한 사진이 포함되어 있습니다.

- 필요 자료: 무료 사이트에서 다운로드 받은 사진 20장
- 촬영 조건: 정면/측면/다수/얼굴 없음
- 파일 이름 규칙: `img_001.jpg`~`img_020.jpg` 또는 `video_01.mp4`, `video_02.mp4`
- 지도교사가 입력 파일 사용 권한을 확인하고 학생에게 배포합니다.
- 정답표의 값은 **추측해서 작성하지 말고 실제 자료를 사람이 확인하고** 입력하세요.
- 해당 입력이 준비되기 전에는 기본 소스가 `FileNotFoundError`로 종료될 수 있으며 이는 정상적인 입력 누락 안내입니다.
